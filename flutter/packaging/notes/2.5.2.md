Songs from YouTube that 2.5.1 still stopped with "This post blocked the download" download now.

- Nazzil asks YouTube as its Apple Vision Pro app first. YouTube now refuses many songs to its Android and iPhone apps unless they send a token proving they are the real app, and it asks the Vision Pro app for none.
- Videos marked as made for kids, which the Vision Pro app cannot play, still download through YouTube's other apps.

## Installing

- **Android**: installs over 2.5.1. If you have 2.4 or older, uninstall it first: this build is signed with a newer key, so Android will not install it over those. What you saved to the gallery stays; the list inside Nazzil starts empty.
- **iPhone**: the IPA is unsigned. Install it with SideStore, AltStore or Sideloadly, which sign it with your Apple ID; a free one works. Apple makes such installs expire after 7 days, and SideStore and AltStore renew them.
- **Windows**: the installer is not signed, so SmartScreen may warn. Choose More info, then Run anyway.
- **Mac**: open the disk image and drag Nazzil onto Applications. The app is not notarised: the first time it is blocked, open System Settings, Privacy & Security, and choose Open Anyway.
- **Linux**: install the .deb with `sudo apt install ./Nazzil-2.5.2-linux-amd64.deb`, or the Flatpak with `flatpak install ./Nazzil-2.5.2-linux-x86_64.flatpak`, which fetches its runtime from Flathub the first time. The AppImage runs after `chmod +x`. The .deb and the AppImage need Ubuntu 24.04, Debian 13, Fedora 40 or newer.
